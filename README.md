# 진화의 정원 (Garden of Evolution)

신경망 기반 인공생명 생태계 시뮬레이터. 모든 생명체는 137개 가중치의 신경망(뇌)을 갖고 태어나며, 아무도 행동을 가르치지 않습니다 — 돌연변이와 자연선택만으로 먹이 추적, 종 분화(초식 → 포식자), 포식자-피식자 진동이 창발합니다.

**[▶ 브라우저에서 바로 실행](https://moriochoradio.github.io/evolution-garden/)**

## 특징

순수 바닐라 JavaScript + Canvas 2D로 작성된 단일 HTML 파일입니다. 서버, 빌드 도구, 외부 라이브러리가 전혀 없으며 오프라인에서도 동작합니다.

- **유전과 진화**: 크기·속도·감각·식성·번식 임계값 + 신경망 가중치가 유전되고 돌연변이됨
- **신경망 뇌**: 입력 12(먹이/이웃의 방향·거리·크기·식성 등) → 은닉 9 → 출력 2(회전·추진)
- **먹이사슬**: 식물 → 초식 → 육식, 사체는 청소부의 먹이가 되어 육식 진화의 다리 역할
- **실시간 관찰 도구**: 개체군 차트, 식성 분포(종 분화 관찰), 형질 지도, 개체 클릭 시 뇌 활성 시각화
- **신의 손**: 먹이 뿌리기, 번개로 솎아내기, 환경 변수 조절
- **저장/불러오기**: 진화시킨 세계를 JSON으로 보존

## 실행

`index.html`을 브라우저에서 열기만 하면 됩니다.

## 검증

시뮬레이션 코어는 DOM과 분리되어 있어 Node.js로 헤드리스 실행이 가능합니다.
60,000틱 장기 테스트에서 절멸 없이 90세대 이상 진화, 평균 이동 속도 3배 향상, 포식자 종 분화를 확인했습니다.
