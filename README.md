# 진화의 정원 (Garden of Evolution)

🇰🇷 한국어 · 🇬🇧 [English](README.en.md)

**아무도 가르치지 않은 신경망이 스스로 사냥을 배우는 인공생명 생태계 시뮬레이터.** 모든 개체는 137개 가중치의 작은 신경망(뇌)을 갖고 태어나고, 돌연변이와 자연선택만으로 먹이 추적·종 분화(초식 → 포식자)·포식자-피식자 진동이 창발합니다. 순수 바닐라 JavaScript + Canvas 2D, **단일 HTML 파일 하나**입니다.

**[▶ 브라우저에서 바로 실행](https://moriochoradio.github.io/evolution-garden/)** — 설치·빌드 없음

## ❓ 왜 만들었나

이 프로젝트의 출발점은 시뮬레이터가 아니라 **모델 실험**이었다. Anthropic의 창작 특화 모델 Fable로 "생성형 모델이 어디까지 만들어 내는가"를 시험해 보려 했고, 주제로 인공생명을 골랐다.

주제를 그렇게 잡은 이유는 **정답을 미리 정할 수 없는 문제**여서다. 화면에 무엇이 나타날지는 만드는 사람도 모른다. 무작위 뇌를 가진 개체들이 대부분 굶어 죽고, 우연히 "먹이 쪽으로 도는" 뇌가 살아남아 퍼지고, 식성이 갈라지며 종이 분화되고, 포식자와 피식자가 서로를 조절하는 진동이 나타난다 — **그걸 설계한 게 아니라 규칙만 주고 지켜보는** 것이 목적이었다.

만드는 방식에도 제약을 하나 걸었다. **단일 HTML 파일, 빌드 없음, 의존성 0개.** 링크만 열면 바로 돌아가야 실험 결과를 남에게 보여줄 수 있다고 봤다.

## 무엇을 볼 수 있나

- **초반**: 무작위 뇌를 가진 개체 대부분은 헤매다 굶어 죽고, 우연히 "먹이 쪽으로 도는" 뇌를 가진 소수가 살아남아 번식합니다. 몇 세대 만에 먹이 추적이 뚜렷해집니다.
- **중반**: 식성(diet)은 0~1 연속값 유전자입니다. **식성 분포 차트가 둘로 갈라지면 종 분화** — 초식 무리에서 포식자 혈통이 갈라져 나온 것입니다. 사체를 먹는 청소부 혈통이 초식 → 육식 사이의 진화적 다리를 놓습니다.
- **장기**: 포식자가 늘면 초식이 줄고, 그러면 포식자도 굶는 **로트카-볼테라 진동**이 개체군 차트에 나타납니다.
- **관찰 도구**: 개체군/식성 분포/형질 지도 차트, 개체 클릭 시 뇌의 실시간 활성 시각화, 이벤트 로그.
- **신의 손**: 먹이 뿌리기, ⚡ 번개로 우점종 솎아내기, 돌연변이율·식물 생장률 등 환경 변수 조절, 세계를 JSON으로 저장/불러오기.

## 왜 이렇게 만들었나 — 기술 선택 Q&A

**Q. 왜 바닐라 JS 단일 HTML 파일인가?**
이 프로젝트의 볼거리는 UI가 아니라 시뮬레이션 자체입니다. 프레임워크·빌드 도구·외부 라이브러리를 전부 빼고 파일 하나(`index.html`, 약 950줄)로 만들면, 누구든 더블클릭 한 번으로 오프라인에서도 돌려볼 수 있습니다. 의존성 0은 데모 접근성이자 제약 조건이었습니다: 렌더링(Canvas 2D), 신경망, 공간 분할까지 전부 직접 작성했습니다.

**Q. 신경망이 왜 137개 가중치뿐인가?**
구조는 입력 12(가장 가까운 먹이/이웃의 방향·거리·크기·식성, 자기 상태 등) → 은닉 9 → 출력 2(회전·추진)의 완전연결망으로, 편향 포함 `9×(12+1) + 2×(9+1) = 137`개입니다. 수백 개체가 매 틱 forward를 돌려야 하므로 작아야 실시간이 나오고, 무엇보다 "이 정도로 작은 뇌도 학습 없이 선택압만으로 사냥을 익힌다"를 보여주는 것이 목적이라 일부러 최소로 잡았습니다.

**Q. 왜 학습(역전파)이 없나?**
개체는 태어난 뇌 그대로 평생을 삽니다. 잘 움직인 개체가 번식하고, 자식의 뇌 가중치에 가우시안 돌연변이가 들어갈 뿐입니다. 보상 함수를 설계하는 순간 "내가 정의한 행동"이 나오므로, 순수 자연선택만으로 무엇이 창발하는지 보는 실험입니다.

**Q. 종 분화를 왜 하드코딩하지 않았나?**
초식/육식을 이산적인 종으로 구현하면 종 분화는 '기능'이지 '창발'이 아닙니다. 대신 식성을 0~1 연속 스펙트럼으로 두고, 사체(고기)라는 중간 먹이 니치를 만들어 잡식 단계도 생존 가능하게 했습니다. 그 결과 분포가 스스로 갈라지는 순간을 차트에서 관찰할 수 있습니다.

**Q. 성능은 어떻게 확보했나?**
이웃 탐색이 병목이라 공간 해시 그리드로 주변 셀만 조회합니다(전수 비교 O(n²) 회피). 핫루프에서는 조회 결과 배열을 재사용해 할당을 줄였습니다.
